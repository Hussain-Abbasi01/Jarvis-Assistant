# 🤖 Jarvis - Python Voice Assistant

An intelligent, voice-controlled virtual assistant built with Python. Jarvis listens to user voice commands to automate daily tasks such as providing real-time date and time updates, as well as launching popular web platforms like Google and YouTube[cite: 3].

---

## ✨ Features
- 🎙️ **Voice Recognition:** Listens and accurately converts spoken commands to executable tasks[cite: 3].
- 🗣️ **Text-to-Speech:** Provides clear audio feedback to the user[cite: 3].
- 🌐 **Web Automation:** Opens Google, YouTube, and other websites instantly via voice commands[cite: 3].
- ⏰ **Date & Time Announcement:** Tells current time and date on request[cite: 3].

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python[cite: 3]
- **Speech Recognition:** `speech_recognition`
- **Audio Output:** `pyttsx3`
- **Browser Control:** `webbrowser`
- **System Utils:** `datetime`
